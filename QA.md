# Testing notes

Run `npm test` to rebuild the browser bundle and exercise the game in a Node VM with the native Skia Canvas implementation. This verifies executable gameplay and raster rendering, with a small DOM/input harness.

Covered checks:

- Rendering and navigation in all twelve districts, including collision-safe paths from each spawn.
- Keyboard movement, atlas/local map, progression, automation, supplies, journal, and pause menus.
- Auto-battle through victory, one-time XP rewards, leveling and talent spending.
- Save/reload in the current runtime and a fresh runtime; migration of older save fields.
- Retreat and starting a challenge-board trial.
- All 125 sprite frames retain their dimensions; retained pixels are byte-identical and cached frames are reused. Targeted checks verify that known background patches disappear while adjoining clothing, furniture, rails and water survive.
- A new game starts with 75–90 HP and 20–36 MP. `npm run test:balance` simulates early fights and level-appropriate bosses across eight random seeds per encounter, checks that the final boss defeats a level-one party, and verifies save migration, skill gating and resource recovery. These automated simulations are balance guardrails, not a substitute for a full player playthrough.

`npm run review:sprites` generates 22 before/after pages in `.tmp/review/`, covering all 54 character frames, 11 props, 5 landmarks, and 55 item/effect frames. These include unchanged frames. All pages were visually inspected on contrasting backgrounds.

`npm run test:world` checks 168 routes with swept collision samples, every NPC and interaction, all six side-mission objective chains, encounter placement, old-save recovery inside new geometry, and the main story through both puzzles and the ending. Story bosses are resolved directly in this route test; seeded combat balance is checked separately. It also checks Hegseth's windup/fire/recovery poses, stationary feet, barrel position, and non-firing support skills.

`node tests/map-layout.mjs` checks 9,764 pairs of rendered scenery bounds, NPCs, encounter spawns, and visible interaction objects across early and late story states. Unlike collision footprints, the measured artwork bounds include raised furniture and foliage. Joined wall corners are intentional; low-alpha shadows are excluded. It also simulates twenty seconds of patrol movement in each district to check clearance around NPCs and interactions, and checks that service focus labels select the available action and stay below the party.

`npm run screenshots` also creates `screenshots/populated-districts.png`, showing all twelve maps with NPCs, encounters, and interaction props, and `screenshots/mall-services.png`, showing the separated service boards and shared focus label. These supplement the static scenery contact sheet, which cannot reveal overlaps caused by live objects.

`npm run test:parity` is a historical refactor comparison against the original map/story implementation. It is intentionally not a gate for the rebuilt districts, which change geometry, interactions, story and rendering.

The README screenshots are game-canvas renders generated by `npm run screenshots`. They are not screenshots from a browser playthrough.

The repaired Hegseth firing sequence in `screenshots/hegseth-firing.png` was reviewed at game scale. A pixel comparison against the preceding actor atlas confirmed that only 1,291 RGB pixels inside his firing frame changed, with no source-alpha changes or changes outside that frame. The full gameplay, sprite, balance, and world/story suites passed after the repair.

No local Chromium executable was available in this environment. Browser-native audio, fullscreen, file dialogs, local-file loading and phone/touch behavior still require a live-browser check. This update uses the existing Canvas 2D APIs.

Existing internal save keys and encounter identifiers are retained for compatibility. They are not public release numbers.
